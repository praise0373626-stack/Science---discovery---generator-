# Science Discovery Generator

An interactive science website that helps users explore interesting scientific facts, search by topic, and test their knowledge with a short quiz.

## Features
- Search for science topics
- Filter by category
- Generate random discoveries
- Open “Learn more” links for deeper reading
- Quick multiple-choice quiz

## Live Demo
https://praise0373626-stack.github.io/science-discovery-generator-/

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Use
1. Open the live site or run the project locally.
2. Type a topic or choose a category.
3. Click “Generate a discovery” to view a fact.
4. Answer the quiz question and explore the linked resources.
